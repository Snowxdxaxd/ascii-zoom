# ASCII-зум: глаз → сфера

Проект по мотивам видео @ch20f3rst (TikTok): окно целиком набрано текстовыми
символами (Tkinter-канвас с сеткой знакомест). Из шума проявляется глаз,
камера влетает в зрачок, через шум собирается красная полосатая сфера со
звездами и бликами, зум уходит в ее ядро — и цикл повторяется.

## Запуск

    python main.py

Нужен только Python с tkinter (стандартная установка Windows).
Выход — Esc или закрыть окно. Прочее:

- `python main.py --selftest` — замер скорости рендера без открытия окна;
- `python preview.py` — те же сцены текстом в терминале (проверка форм).

## Как устроено

- Каждый кадр считается яркость каждой ячейки: `eye_b` — глаз (радужка с
  радиальными волокнами, лимбальное кольцо, вены на склере, блик), `orb_b` —
  сфера (полосы, ореол, темный центр с горячим ядром), шум — случайные значения.
- Яркость превращается в пару (символ, цвет): символ берется из бакетов
  `BUCKETS` по плотности (случайный внутри бакета — отсюда мерцание), цвет —
  из палитры `PALETTES`.
- Зум экспоненциальный: координаты делятся на `z = 2**(t/период)`, поэтому
  влет в зрачок и в ядро сферы ускоряется, как в оригинале.
- `cv.itemconfig` у Tk медленный (~20 мкс на ячейку), поэтому за тик
  обновляется бюджет ячеек: курсор бежит по сетке по кругу и обновляет только
  изменившиеся, стоимость ячейки меряется EMA (`st["cell"]`), из нее
  считается бюджет (`st["budget"]`) и частота кадров — та же схема, что в
  коде из видео.

## Настройка (шапка main.py)

- `W`, `H` — размер окна; `FONT` — шрифт и кегль (плотность сетки; чем крупнее
  шрифт, тем меньше ячеек и выше fps).
- `SEGMENTS` — длительности сцен и полупериод зума (скорость влета).
- `PALETTES` — цвета сцен; `TARGET_MS` — целевое время кадра.
